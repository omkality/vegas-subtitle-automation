# Выбор модели после ручной разметки

Замеры выполнены 17 ноября 2026 года на RTX 4070 Ti SUPER 16 GB.
Проверены 12 конфигураций 11 моделей из пяти семейств. Все прогоны работали
последовательно на GPU. Никакие веса на пользовательских данных ещё не обучались.

Для первого дообучения оставлен **GigaAM v3 RNN-T**. На validation он разделил
первое место с GigaAM E2E CTC: 21 ошибка на 46 словах. Raw-формат русского текста
подходит текущим обучающим меткам. Это рабочий выбор для следующего эксперимента,
статистически доказанного единственного победителя на таком наборе нет.

| Модель / конфигурация | WER validation, 14 примеров | WER development, 98 примеров | Семейства мата, совпадения |
| --- | ---: | ---: | ---: |
| GigaAM v3 E2E CTC | 45.7% | 49.3% | 51/52 |
| GigaAM v3 RNN-T | 45.7% | 44.6% | 51/52 |
| GigaAM v3 CTC | 50.0% | 45.4% | 50/52 |
| GigaAM v3 E2E RNN-T | 50.0% | 49.3% | 50/52 |
| GigaAM Multilingual 600M | 52.2% | 43.6% | 46/52 |
| Whisper large-v3 | 56.5% | 42.6% | 45/52 |
| T-one, greedy без KenLM | 65.2% | 55.4% | 44/52 |
| GigaAM Multilingual 220M | 67.4% | 49.9% | 44/52 |
| Qwen3-ASR 1.7B | 69.6% | 55.9% | 36/52 |

| Whisper Russian, greedy | 87.0% | 57.4% | 43/52 |

Validation содержит только 14 фрагментов и 46 слов, преимущественно сложные
случаи. Одна ошибка меняет WER на 2,17 процентного пункта. Development включает
84 будущих обучающих примера. Его результат служит диагностикой и не является
независимым test. Прямое сравнение с прежними числами на 66 монтажных подписях
некорректно, состав и границы аудио различаются.

Large-v3 показал наименьший общий WER на 98 примерах. GigaAM RNN-T лучше сохранил
словарные семейства мата. Эти выводы относятся к данному пилоту. Подсчёт мата
является эвристической лексической диагностикой. Он не измеряет границы сигнала,
остатки слышимого слова или качество всей будущей цензуры.

Русская адаптация Whisper проверялась с beam=5 и greedy. С beam=5 возникали
длинные повторения. Greedy сократил такие сбои, но не сделал эту конфигурацию
лучшей на validation. T-one проверен с greedy без KenLM. GPU execution для него
подтверждён ONNX-профилем с CUDA kernels. Другие модели использовали штатные
локальные CUDA-бэкенды. Настройки каждого прогона сохраняются в summary.json.

## Данные и воспроизводимость

Из 120 решений приняты 98, отклонены 15, семь ожидают полного подтверждения.
82 train и 14 validation проходят кириллический алфавит GigaAM. Две строки с
SSG и 5.56 сохранены в общем JSONL и исключены только из GigaAM TSV до уточнения
произнесённой формы. Приватные аудио, тексты, гипотезы и отчёты находятся в local/.

68 примеров из четырёх групп остаются в holdout. Они не подавались ASR или aligner,
не включались в очередь и не использовались при выборе. Общие SHA256 набора,
аудио и весов проверяются при запуске и построении comparison-report.

Исходные модели закреплены commit revision и SHA256 в configs/models.lock.json.
GigaAM использует официальный native-код по закреплённому commit и строгую
загрузку весов. Qwen, Parakeet и русская адаптация Whisper используют штатные
Transformers-классы и локальные safetensors. Произвольный remote code из моделей
не исполняется. Образы и зависимости закреплены digest и lock-файлами.
