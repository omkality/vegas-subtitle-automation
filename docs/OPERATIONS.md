# Сборка и выпуск

Базы контейнеров закреплены по версии и digest. Python-зависимости устанавливаются
из lock-файлов с проверкой хешей и только из готовых wheel-файлов. В финальных
образах нет CUDA SDK, компиляторов или PyTorch. Запуск выполняется с UID 1000.
FFmpeg поставляется в зафиксированной зависимости imageio-ffmpeg, отдельный
пакет с графическими зависимостями ОС не устанавливается.

CUDA 12.8.1/cuDNN 9 и Python 3.12 выбраны для проверенного стека CTranslate2.
Новая версия сама по себе не доказывает лучшего качества ASR. Обновления баз,
lock-файлов и GPU-библиотек проходят тесты и локальную проверку CUDA.

CI проверяет PR и main. Он не получает доступ к приватному корпусу, секретам
моделей или GPU. CPU-образ используется для тестов и обработки метаданных.
Распознавание проверяется в отдельном GPU-контейнере локально.

Release workflow публикует CPU/GPU-образы в GHCR только после push релизного
тега. Имена включают версию и SHA коммита. Плавающий latest не создаётся.
Привилегии packages:write выданы только release job. Публикация не выполняется
из pull request. SBOM и provenance включены. Actions закреплены commit SHA.

Сам release workflow пока не запускался в GitHub. Его наличие в репозитории
не означает состоявшуюся публикацию или успешное удалённое выполнение CI.

Для обновления Python lock-файлов используйте uv pip compile с теми же extras
и --generate-hashes. Проверяйте изменения в PR и повторяйте тесты. Загрузка
новых версий не должна происходить при каждом запуске inference.
