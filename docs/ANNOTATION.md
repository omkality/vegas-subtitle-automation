# Проверка речевой разметки

Проверяйте дословные слова, говорящего и границы выделения. Подсказки моделей
раскрываются отдельно. Они помогают найти ошибку, но не подтверждают разметку.
Мат записывается полностью, без звёздочек. Числа и названия для GigaAM лучше
записывать произнесёнными русскими словами.

## Работа в интерфейсе

1. Прослушайте выделение. При необходимости послушайте весь доступный контекст.
2. Передвиньте голубые границы так, чтобы выбранные слова звучали целиком.
3. Впишите только слова внутри итогового выделения и проверьте говорящего.
4. Выберите полное покрытие звука и отдельно подтвердите текст и границы.
5. Отклоните шум, неразборчивую речь и голоса людей, которых нельзя надёжно
   отнести к двум размечаемым участникам. Оборванные слова не дописывайте по смыслу.

Если доступный контекст всё ещё обрывается, можно оставить только целые слова
внутри него. Если это не даёт пригодного примера, отметьте обрыв и проверьте
только текст либо отклоните пример. Проверка одного текста сохраняется, но
обучающий экспорт требует также подтверждения границ.

Прогресс сохраняется на сервере автоматически. Перед закрытием дождитесь
«Все изменения сохранены». Кнопка «Скачать JSON» создаёт дополнительную копию.
Страница содержит 20 примеров, есть переход по номеру и к первому непроверенному.
Номер страницы хранится в URL с идентификатором текущей пачки.

## Следующая пачка

Каждая пачка получает отдельный файл очереди и ответов. Исключайте все прежние
очереди, включая отклонённые и пока не подтверждённые примеры. Старые ответы
нельзя заменять пустой новой разметкой. `test` и `holdout` не попадают в очередь.

```powershell
docker compose run --rm tools prepare-review-batch `
  --exclude-batch local/review-batches/current.json `
  --selection balanced --limit 1000 `
  --output local/review-batches/batch-002-selection.json

docker compose run --rm tools extend-review-context `
  --batch local/review-batches/batch-002-selection.json `
  --output local/review-context-batch-002 --padding 2.5 --workers 4
```

`balanced` чередует группы записей, голоса, split и длины фрагментов. Это
очередь для разметки, она не считается случайной репрезентативной оценкой ASR.
`--exclude-batch` можно повторить для всех предыдущих пачек.

Расширение контекста создаёт новую базу с собственным SHA256. Исходная база,
готовые ответы, ID и split примеров сохраняются. Исходные WAV переиспользуются,
дополнительный контекст извлекается из оригинальных записей. Начальное выделение
покрывает прежнюю реплику. При увеличении выделения текст должен соответствовать
новым границам. Новые примеры автоматически не подтверждаются.

Чтобы открыть новую пачку, задайте в локальном `.env`:

```dotenv
VEGAS_REVIEW_DATASET=local/review-context-batch-002/dataset.json
VEGAS_REVIEW_BATCH=local/review-context-batch-002/batch.json
VEGAS_REVIEW_SAVED=local/reviews/batch-002.json
```

Затем обновите только сервис разметки и перезагрузите вкладку:

```powershell
docker compose build tools
docker compose --profile review up -d --no-deps --wait review
```

Сервис слушает `http://127.0.0.1:8765/`. Старые вкладки не могут сохранить ответы
для другой версии базы. После проверки используйте `export-reviewed` с `--dataset`,
указывающим на базу именно этой пачки.
